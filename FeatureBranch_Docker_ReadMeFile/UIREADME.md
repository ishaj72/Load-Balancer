# Load Balancer UI

A simple frontend dashboard built using HTML, CSS, and JavaScript to interact with the Spring Boot Load Balancer.

The UI provides a simple way to monitor registered backend servers and test Round Robin load balancing.

## Technologies

- HTML
- CSS
- JavaScript
- Fetch API

## Features

- Load Balancer status
- Registered backend server list
- Backend server ports
- Send requests through the Load Balancer
- Display the backend that handled the request
- Request count for each backend
- Round Robin request distribution
